## About Me

<img align="right" src="[media.giphy.com](https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif)" width="280"/>

I'm a **Data Analyst (Fresher)** based in India, passionate about transforming messy, unstructured data into clean insights that actually drive decisions. I enjoy working across the full data lifecycle — from collection and cleaning to visualization and storytelling.

- 🔍 Currently sharpening my skills in **SQL, Python, and Data Visualization**
- 📊 Fascinated by dashboards, trends, and the "why" behind the numbers
- 🌱 Actively learning **AI, System Design, Docker, AWS & DevOps**
- 💬 Open to entry-level Data Analyst / Junior Developer opportunities
- ⚡ Fun fact: I believe every dataset has a story — my job is to find it
